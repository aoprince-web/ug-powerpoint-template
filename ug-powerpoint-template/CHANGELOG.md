# Changelog

## Improved validation release

- Added clear validation for JSON structure, required slide fields, supported slide types, image files and bundled assets.
- Added slide-specific error messages and output-directory creation.
- Reopens saved PowerPoint files and checks slide count before reporting success.
- Improved conservative text-fit estimation and made bullet paragraph spacing more consistent.
- Reserved room for image captions before scaling split-slide images.
- Expanded workflow guidance for source fidelity, references, restyling, visual QA and transparent delivery.
- Added automated tests for all supported slide types and common malformed inputs.
- Preserved the original University of Ghana PowerPoint template and crest assets.
